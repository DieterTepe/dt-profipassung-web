# DT-ProfiPassung – Toleranzen & Passungen nach ISO 286

**DT-ProfiPassung** ist eine professionelle Web-Anwendung zur schnellen und präzisen Berechnung von Toleranzen und Passungen im Maschinen- und Anlagenbau. Die Software ermittelt auf Basis aktueller Normen alle relevanten Grenzmaße und Toleranzfelder.

## 🚀 Live-Testversion
Probieren Sie die Web-App direkt im Browser aus:
👉 **[DT-ProfiPassung Testversion starten](https://dietertepe.github.io/dt-profipassung-web/DT-ProfiPassung_Testversion.html)**

## ✨ Funktionen
* **Normenkonforme Berechnung:** Vollständige Unterstützung der ISO 286-1:2019 und ISO 286-2:2020.
* **Echtzeit-Ergebnisse:** Die Berechnung erfolgt unmittelbar nach der Eingabe der Werte (in µm und mm).
* **Visuelles Toleranzfeld:** Dynamische Anzeige der Toleranzfeld-Grafik zur besseren Veranschaulichung.
* **Flexibler Datenexport:** Speichern und Laden im `.dtp`-Format sowie Export als PDF/Druck oder Word-Dokument (`.rtf`).

## 🛠️ Technische Details
* **Architektur:** Reine Client-Side Web-App (HTML5, JavaScript, CSS).
* **Sicherheit:** Keine Datenübertragung an externe Server – alle Berechnungen laufen lokal im Browser.
